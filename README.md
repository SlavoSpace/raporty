# Raporty — raporty.dysza.app

Raport dzienny załóg Pracowni Sushi (Restauracja, Fabryka, Transport) — zamiast formularzy RAPORT DZIENNY.
Ta sama baza Supabase co Tablica Mocy i Spis; konta raportów (jedno miejsce na konto) zakłada kierownik w aplikacji.
Maile, plik dnia RD, lista obecności i plik Z robi ZDZISŁAW (Raporty Dzienne 3.0).
